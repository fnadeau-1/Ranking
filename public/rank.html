Rank Dashboard

Manage the roster, build each week's order, and publish it live.

  1. Pick a week, then each weight class — last week's order loads so you only tweak it. All 14 classes are shown as tabs (green dot = submitted). Need a new week? Use + New week next to the picker.
  2. Fill the ranking: drag wrestlers in (or use the ▲/▼ arrows on a phone), or click + Add wrestler on an empty slot to create one on the spot.
  3. Go live with Submit all 14 — it publishes every weight class for the week at once. Remove from public takes the week back down, and Full View reviews all 14 before you submit.
You need ranker access to use this page. Sign in, then ask an existing ranker to add your account, or see the README to bootstrap the first ranker.
